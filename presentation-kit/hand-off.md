## Recommended use

1. Open the live entry and confirm F-4412 loads before the meeting.
2. Keep this folder's `backup.html` available in a second tab.
3. Run the seven-minute story once. For the short route, use the clearly labeled prepared checkpoints from the same isolated case.
4. Follow the visible buyer / seller role change. Read the current review before confirming an action.
5. Finish on **Prepare application information.** Explain that the customer supplies mounting details, speed and load before engineering can review; the plan remains acknowledged and the findings remain open. **Export example case** is a local download. Use the 250-to-300 waiting example only if discussing returning-customer follow-up.
6. Use **Open optional capability preview** only when useful. Its crank model and data are a separate sample, outside the customer's business next step. Return to F-4412 afterward.
7. For a phone proof, follow the script's 45–60 second sequence. Show question → model → question → v2, then a separate Studio customer preview. Use **Back to Studio** or **Return to F-4412** to keep the return obvious.

The dedicated Patrick presentation does not replace the existing NHI workspace, separate sample or earlier guide. Browser-local data does not travel automatically with this ZIP. Starting another presentation run archives the current run inside this presentation's own storage. Guide → **Export earlier presentation runs** keeps those archives available. Review and confirmation remain explicit at inquiry, change, quotation and engineering-plan handoffs.
